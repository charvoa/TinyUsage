# Support

TinyUsage is a source-only project maintained by NUGGETS CONSULTING FZCO.

- Use GitHub Discussions for setup questions and feature ideas.
- Use Issues for reproducible bugs with a sanitized environment description.
- Do not paste API keys, OAuth tokens, cookies, provider responses, account emails or home-directory paths.
- Provider private endpoints are experimental and can break without notice.
- Background refresh and Live Activity updates are opportunistic; the Mac cannot wake an iPhone over Bonjour.

Before opening an issue, run the latest `main`, try `make generate`, and confirm that both devices can reach each other on the same local network.
