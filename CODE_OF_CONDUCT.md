# Code of Conduct

TinyUsage follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

We welcome contributors of every experience level. Be specific, kind and constructive. Harassment, discrimination, doxxing, credential sharing and hostile provider-targeting are not acceptable.

Report unacceptable behavior privately to the maintainer through the repository's private contact or GitHub reporting tools. Do not expose personal data or secrets in a report.
